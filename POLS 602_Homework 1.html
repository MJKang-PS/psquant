# Create a function that calculates the three estimates
variance_estimators <- function(x) {
  
  # Number of observations in the sample
  n <- length(x)
  
  # Variance estimator dividing by n
  var_n <- sum((x - mean(x))^2) / n
  
  # Sample variance dividing by n-1
  sample_var <- var(x)
  
  # Sample standard deviation
  sample_sd <- sd(x)
  
  # Return the three estimates
  c(var_n = var_n,
    sample_var = sample_var,
    sample_sd = sample_sd)
}

Answer: No, s is not an unbiased estimator of σ = 2. Its estimated bias is approximately -0.112 at n = 5, -0.067 at n = 10, -0.008 at n = 30, 0.001 at n = 100. The results show that s tends to underestimate σ, especially at small sample sizes and the bias gets smaller as n grows. This happens even though s² is unbiased for σ². Because taking the square root is a nonlinear transformation, unbiasedness does not necessarily survive a nonlinear transformation.

Answer: The standard deviation of the 1,000 divide-by-n variance estimates is 2.316, while the standard deviation of the 1,000 sample variance estimates is 2.895. Therefore, the divide-by-n estimator is less variable. This is because it equals the sample variance multiplied by (n − 1)/n = 0.8, which shrinks the spread of the estimates.

However, this does not make it the better estimator. Estimator quality depends on both bias and variability. The divide-by-n estimator is downward biased, so its estimates are tightly clustered around the wrong value. In contrast, the sample variance is unbiased for the true population variance, even though it is more variable.

# Create a function that generates one dataset from the true process
make_data <- function(n, rho) {
  
  # Generate z (political interest) from N(0, 1)
  z <- rnorm(n, mean = 0, sd = 1)
  
  # Generate u (the part of x unrelated to z) from N(0, 1)
  u <- rnorm(n, mean = 0, sd = 1)
  
  # Generate the error term from N(0, 1)
  epsilon <- rnorm(n, mean = 0, sd = 1)
  
  # Generate x (news consumption) so that its correlation with z is rho
  x <- rho * z + sqrt(1 - rho^2) * u
  
  # True parameter values
  beta0 <- 1
  beta1 <- 2
  beta2 <- 3
  
  # Generate y (political knowledge) from the true model
  y <- beta0 + beta1 * x + beta2 * z + epsilon
  
  # Return the data as a data frame
  data.frame(y, x, z)
}

Answer: With rho = 0, leaving out z no longer biases the estimate. The x coefficient from y ~ x is 2.04 (95% CI: 1.84 to 2.24), which includes the true value of 2 and matches the 2.02 from the true model. Omitted variable bias only appears when the left-out variable is related to both x and y. Here z affects y but is unrelated to x, so x doesn’t pick up any of its effect.

This means we should include variables that affect y and are related to x, based on theory, since leaving them out biases the estimate and more data won’t fix it. Since we never know rho in real data, we can’t count on omitted variables being harmless.
